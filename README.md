# Віджет «Інвертор» для Android

Показує на головному екрані заряд АКБ (%) і навантаження (W) з хмари SmartESS / DessMonitor.
Сервер не потрібен: застосунок сам ходить у хмару з вашим логіном SmartESS.

- Автооновлення раз на 15 хв (мінімум Android); натискання на віджет оновлює одразу.
- Хмара DessMonitor сама оновлює дані приблизно раз на 5 хв.
- Колір заряду: зелений від 50 %, жовтий 20–49 %, червоний нижче 20 %.

## Як зібрати APK

**Через GitHub (без Android Studio):**
1. Створіть репозиторій на GitHub і завантажте туди вміст цієї папки.
2. Вкладка Actions → «Build APK» запуститься сама (або Run workflow).
3. Через 3–5 хв у результатах запуску буде артефакт `inverter-widget-apk` → у ньому `app-debug.apk`.

**Через Android Studio:** File → Open → ця папка → Build → Build APK(s).

## Налаштування
1. Встановіть APK (дозвольте встановлення з цього джерела).
2. Відкрийте «Інвертор», введіть логін і пароль SmartESS → «Зберегти й перевірити».
   Знизу з'явиться список усіх полів з хмари — знадобиться, якщо щось показується не так.
3. Довге натискання на головному екрані → Віджети → «Інвертор».
4. Якщо віджет не оновлюється у фоні: Налаштування → Застосунки → Інвертор → Батарея → «Без обмежень».
